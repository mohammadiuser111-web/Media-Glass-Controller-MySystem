# Media Glass Controller - MySystem

باکس افقی و شیشه‌ای ویندوز 11 برای کنترل ویدیوی YouTube و رسانه‌های درحال پخش.

## امکانات

- استفاده از Thumbnail ویدیو فقط به‌صورت پس‌زمینهٔ Blur؛ بدون نمایش تصویر جداگانه.
- نمایش نام ویدیوی درحال پخش در بالای کنترلر.
- ساخت خودکار رنگ و تم باکس از تصویر همان ویدیو.
- پس‌زمینهٔ Blur و Acrylic هماهنگ با ویندوز 11.
- نمایش خط زمان و امکان جابه‌جایی در ویدیو.
- دکمه‌های Play/Pause، قبلی و بعدی.
- امکان کشیدن باکس و قرار دادن آن در هر قسمت صفحه.
- قفل‌کردن موقعیت و اندازهٔ باکس.
- همیشه بالاتر از پنجره‌های دیگر.
- ذخیرهٔ خودکار مکان، اندازه و وضعیت قفل.
- پشتیبانی از Chrome، Edge، Firefox و برنامه‌هایی که Windows Media Session دارند.

## نصب

1. از بخش **Releases** فایل `MediaGlass-win-x64.zip` را دانلود کنید. برای ویندوز ARM فایل `win-arm64` را بگیرید.
2. فایل ZIP را Extract کنید.
3. `MediaGlass.exe` را اجرا کنید.
4. یک ویدیو یا آهنگ را در YouTube پخش کنید؛ اطلاعات آن به‌صورت خودکار در باکس نمایش داده می‌شود.

نیازی به نصب .NET نیست.

## استفاده

- برای جابه‌جایی، قسمت خالی باکس را با ماوس بکشید.
- دکمهٔ قفل، موقعیت و اندازه را ثابت می‌کند؛ باکس همچنان همیشه روی پنجره‌های دیگر می‌ماند.
- برای Seek، نشانگر خط زمان را بکشید یا روی مسیر آن کلیک کنید.
- قابلیت‌های قبلی و بعدی به پشتیبانی همان ویدیو و مرورگر بستگی دارد.

اگر رسانه شناسایی نشد، در تنظیمات مرورگر قابلیت **Hardware Media Key Handling / Media Session** را فعال کنید و صفحهٔ YouTube را یک‌بار Refresh کنید.

## ساخت پروژه

پیش‌نیاز: Visual Studio 2022 یا .NET 8 SDK روی ویندوز 11.

```powershell
dotnet publish src/MediaGlass/MediaGlass.csproj -c Release -r win-x64 --self-contained true
```
